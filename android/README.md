# Приложение «Табличка» — Android

Открывается в Android Studio как обычный проект: **File → Open** → выбрать
папку `android`. Gradle-обёртка в комплекте, Android Studio сама предложит
скачать нужный SDK.

## Прежде чем запускать — поднимите бэкенд

Приложению нужен сервер: без него камера снимет фотографию, но узнавать будет
некого. Из корня репозитория:

```bash
pip install -r requirements.txt
python3 tools/seed_demo.py --db data/demo.sqlite3          # 4 таблички для проверки
ZDES_DB=data/demo.sqlite3 uvicorn zdes.api:app --host 0.0.0.0 --port 8000
```

Проверить, что поднялся: `curl localhost:8000/health`.

## Куда смотрит приложение

Адрес сервера задаётся одной строкой в `app/build.gradle.kts`:

```kotlin
buildConfigField("String", "API_BASE", "\"http://10.0.2.2:8000\"")
```

| Где запускаете | Что подставить |
|---|---|
| Эмулятор Android Studio | `http://10.0.2.2:8000` — так эмулятор видит localhost компьютера |
| Телефон в той же Wi-Fi | `http://192.168.X.X:8000` — IP компьютера (`ip addr` или `ifconfig`) |

Для телефона сервер должен слушать `--host 0.0.0.0`, иначе он виден только
самому компьютеру.

## Что уже работает

- Камера с рамкой-подсказкой, фонариком и сжатием снимка до 1600 px
- Отправка фото с координатами на распознавание
- Уверенное совпадение → карточка персоны; неуверенное → выбор из кандидатов
- Экран неудачи с выходами «снять ещё раз» и «таблички рядом»
- Карточка персоны: связь с домом, произведения, постройки с расстоянием,
  связи, источники
- Переходы по связям с возвратом по цепочке, а не на камеру
- «Таблички рядом» по геолокации

## Проверка без камеры

Эмулятор снимает синтетическую картинку, на которой распознавать нечего.
Чтобы проверить сопоставление и экраны, у сервера есть отладочный вход:

```bash
ZDES_DEBUG_TEXT=1 ZDES_DB=data/demo.sqlite3 uvicorn zdes.api:app --port 8000

curl -X POST localhost:8000/v1/recognize \
  -F "text=ЗДЕСЬ ЖИЛ АРХИТЕКТОР КОНСТАНТИН МЕЛЬНИКОВ" \
  -F "lat=55.75088" -F "lon=37.58817"
```

В проде вход выключен: он работает только при `ZDES_DEBUG_TEXT=1`.

## Распознавание настоящих фотографий

Сервер по умолчанию ждёт мультимодальную модель:

```bash
pip install anthropic
export ANTHROPIC_API_KEY=...
```

Выбор движка — `ZDES_OCR=claude|paddle|tesseract|yandex|gcv`.
Обоснование каскада — `docs/04-ADR-001-raspoznavanie.md`.
